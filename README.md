## Featured projects

### [Wortschatz](https://wortschatz-delta.vercel.app): AI German vocabulary app
A multi-user web app where one word becomes a full dictionary entry (meaning, gender, plural, IPA, examples, tags) and gets filed into a category tree.
- AI output is validated with Zod, and every category ID is verified on the server, so suggestions stay clean
- SM-2 spaced-repetition engine with a deterministic daily deck, review sets, memory scores, and an opt-in leaderboard
- Works with Gemini, Groq, OpenRouter, Ollama, Anthropic, and OpenAI using per-user keys
- **Stack:** Next.js, React, TypeScript, Prisma, PostgreSQL, NextAuth, Vercel AI SDK
- **Live:** [wortschatz-delta.vercel.app](https://wortschatz-delta.vercel.app)

### Wijha: SAT/ACT tutoring directory
A public directory of SAT/ACT courses in the Middle East, replacing courses scattered across WhatsApp groups.
- Search and filters by category, level, grade, and exam date
- Role-based dashboards for teachers, collaborators, and admins, with approval workflows and admin chat
- **Stack:** Next.js 14, TypeScript, PostgreSQL, Prisma, NextAuth, custom CSS design system

### Green Breeze: smart home hub *(in development)*
A fullscreen touchscreen kiosk app with Home Assistant at its core.
- Frontend with five views, a theme engine, and a draggable widget system
- Python (FastAPI) services: a real-time device bridge, a device-pairing backend, and a mock Home Assistant server
- **Stack:** React, TypeScript, Vite, Python, FastAPI, WebSockets

### Smart Climate & Plant-Care System
Led my school's team at the **Innov8 international competition**.
- Two ESP32 devices: an indoor control hub with sensors and a joystick UI, and an outdoor weather and irrigation module
- A neural network decides when to run the AC, open ventilation, or water plants
- **Stack:** ESP32, C++, Python, Wi-Fi communication
